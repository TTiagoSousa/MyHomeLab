v1.2.0 — GamesTracker, Claude API e documentos em árvore

### Novidades
- **GamesTracker Vault**: liga a tua prateleira de jogos com um token pessoal. Mostra os jogos, as horas e a nota média, avisa de versões novas, faz backups da base de dados, e um novo agente, o Curador de Jogos, vê e muda a prateleira, procura jogos e segue preços.
- **Claude API**: em Definições → IA escolhes entre o Claude Code e a Claude API (paga ao uso, com a tua chave). Quem já usa o Claude Code continua nele.
- **TREK e openGym pelo MCP**: com o Claude Code, os agentes ligam-se diretamente ao MCP de cada app (no openGym, com um token de API em Apps → openGym → MCP); com a Claude API, usam as ferramentas do MyHomeLab.
- **Documentos**: mapas gerados sozinhos para as apps e os servidores, secções tuas e subdocumentos em árvore.
