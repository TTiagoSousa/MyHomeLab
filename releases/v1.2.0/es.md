v1.2.0 — GamesTracker, Claude API y documentos en árbol

### Novedades
- **GamesTracker Vault**: conecta tu estantería de juegos con un token personal. Muestra los juegos, las horas y la nota media, avisa de versiones nuevas, hace copias de la base de datos, y un nuevo agente, el Curador de Juegos, ve y cambia la estantería, busca juegos y sigue precios.
- **Claude API**: en Ajustes → IA eliges entre Claude Code y la Claude API (de pago por uso, con tu clave). Quien ya usa Claude Code sigue con él.
- **TREK y openGym por MCP**: con Claude Code, los agentes se conectan directamente al MCP de cada app (en openGym, con un token de API en Apps → openGym → MCP); con la Claude API, usan las herramientas de MyHomeLab.
- **Documentos**: mapas generados solos para las apps y los servidores, secciones tuyas y subdocumentos en árbol.
