v1.6.0 — Fotos, documentos y horas

### Novedades
- **Immich**: conecta tu biblioteca de fotos con una clave de API. El nuevo Curador de Fotos encuentra fotos (también por descripción, como "playa al atardecer"), ordena álbumes, pone nombre a las personas, muestra los duplicados y cuida el servidor — las colas de tareas, una copia de la base de datos al momento y los ajustes, mostrando siempre lo que cambia antes de aplicarlo. Nunca borra fotos. Las copias guardan la base de datos de Immich; con avisos de versión nueva.
- **Paperless-ngx**: conecta tus documentos escaneados con un token de la API. El nuevo Archivista busca en el texto completo, lee un documento para responder ("¿cuánto pagué?"), ordena documentos de uno en uno o varios a la vez (con confirmación), crea etiquetas, remitentes y tipos que se asocian solos a los documentos nuevos, muestra las tareas que fallaron y cambia la configuración (antes → después, con confirmación). Nunca borra documentos. Las copias guardan la organización y la configuración en JSON; con avisos de versión nueva.
- **solidtime**: conecta tu registro de horas con un token personal. El nuevo Gestor de Horas pone y para el cronómetro, registra horas olvidadas en tu hora local, cambia registros (mostrando el anterior), suma las horas por día, proyecto o cliente y crea proyectos, clientes, tareas y etiquetas. Las copias guardan la exportación completa de la organización.
- **Iconos de las apps**: todas las apps conectadas muestran ahora su logotipo oficial, con los colores de la marca.
- Cada app nueva tiene una página Conexiones con las llamadas a la API que hace MyHomeLab y si tu token o tu papel las permite.
