v1.6.0 — Fotos, documentos e horas

### Novidades
- **Immich**: liga a tua biblioteca de fotos com uma chave de API. O novo Curador de Fotos encontra fotos (também pela descrição, como "praia ao pôr do sol"), arruma álbuns, dá nome às pessoas, mostra os duplicados e cuida do servidor — as filas de tarefas, um backup da base de dados na hora e as definições, mostrando sempre o que muda antes de aplicar. Nunca apaga fotos. Os backups guardam a base de dados do Immich; com avisos de versão nova.
- **Paperless-ngx**: liga os teus documentos digitalizados com um token da API. O novo Arquivista procura no texto todo, lê um documento para responder ("quanto paguei?"), arruma documentos um a um ou vários de uma vez (com confirmação), cria etiquetas, correspondentes e tipos que se associam sozinhos aos documentos novos, mostra as tarefas que falharam e muda a configuração (antes → depois, com confirmação). Nunca apaga documentos. Os backups guardam a arrumação e a configuração em JSON; com avisos de versão nova.
- **solidtime**: liga o teu registo de horas com um token pessoal. O novo Gestor de Horas põe e para o cronómetro, regista horas esquecidas na tua hora local, muda registos (mostrando o de antes), soma as horas por dia, projeto ou cliente e cria projetos, clientes, tarefas e etiquetas. Os backups guardam o export completo da organização.
- **Ícones das apps**: todas as apps ligadas mostram agora o logótipo oficial, nas cores da marca.
- Cada app nova tem uma página Ligações com as chamadas à API que o MyHomeLab faz e se o teu token ou o teu papel as deixa.
