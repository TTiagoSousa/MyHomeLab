v1.20.0 — Empezar de nuevo las actualizaciones con el tablero limpio

### Cambios
- **Limpiar las actualizaciones terminadas**: MyHomeLab ya puede borrar las actualizaciones terminadas (hechas, fallidas y canceladas), con las tareas del tablero, los comentarios, los intentos y los registros de los estudios, para que las actualizaciones empiecen de nuevo con el tablero limpio. Una versión que se canceló y nunca se instaló vuelve a aparecer como disponible.
